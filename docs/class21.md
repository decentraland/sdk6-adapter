# TextShape (SDK6 class 21)

Sources: SDK6 6.12.4 `package/dist/src/index.js` (`TextShape` constructor, `Font`, `Fonts`); the legacy renderer `unity-renderer/Assets/Scripts/MainScripts/DCL/Components/TextShape/TextShape.cs` (`TextShape.cs`), its font table `Components/Font/DCLFont.cs`, and its SDK7 handler `DCLPlugins/ECS7/ECSComponents/TextShape/ECSTextShapeComponentHandler.cs`; the SDK7 `PBTextShape` (`decentraland/sdk/components/text_shape.proto`); the bevy engine `crates/scene_runner/src/update_world/text_shape.rs` (`text_shape.rs`); the adapter `src/components-bridge/TextShape.ts`.

The adapter emits one `core::TextShape` per SDK6 `text` component. Absent payload fields take the legacy renderer model defaults (`TextShape.cs:17-52`), not the SDK6 constructor defaults, because the renderer only ever saw the wire payload. Library-built scenes always send every constructor field, so the two default sets only diverge for hand-built payloads.

## Font size units

The adapter forwards the SDK6 font size unscaled. The legacy renderer assigned the SDK6 size straight to `TextMeshPro.fontSize` on a scale-1 prefab (`TextShape.cs:180`, `TextShape.prefab` `m_LocalScale 1`). The same renderer assigned the SDK7 size straight to the same property (`ECSTextShapeComponentHandler.cs:92`). unity-explorer does the same (`TMPProSdkExtensions.cs:44`). Bevy calibrates its pixels per metre against that reference (`text_shape.rs:170-176`). One SDK6 unit therefore equals one SDK7 unit.

## Engine gaps

Bevy ignores outline, shadow, line spacing and line count. Those fields still travel in the component so a Unity explorer renders them. Bevy clips a wrapped text to its `height` box. The legacy renderer let it overflow.

## Tests

`test/text-shape.cjs` boots `dist/index.js`, creates a `text` component through `componentCreated`, `attachEntityComponent` and `componentUpdated`, ticks, and reads the emitted `core::TextShape` and `core::Billboard` from the snapshot. It asserts every field of 64 seeded permutations against the table, then five literal cases written by hand from `TextShape.cs`, the wrapping matrix, outline, shadow, the 11 by 11 alignment word matrix, empty and undefined values, the font size rules, line and padding rules, the text billboard flag alone, the scene Billboard (class 32) co-occurrence in both attach orders through removal and disposal, the `updateEntityComponent` path and disposal.
